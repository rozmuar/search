Рекомендации

Начните вводить название товара и выберите из списка. Такие товары показываются в рекомендациях в первую очередь.

Если вручную выбранных товаров не хватает до лимита, добираем товарами, подходящими под эти правила (например бренд, цвет).

Вставьте на любую страницу сайта (обычно - главная). Параметр category необязателен - если указан, рекомендации показываются только из этого раздела (категории товара).

<div id="search-recommendations"></div>
<script src="/recommendations.js"></script>
<script>
  SearchRecommendations.init({
    apiKey: 'ВАШ_API_КЛЮЧ',
    container: '#search-recommendations',
    category: 'Ноутбуки' // необязательно
  });
</script>

Формат товарного фида

Подробная инструкция по созданию XML-фида для SearchPro

Что такое товарный фид?

Товарный фид — это XML-файл, содержащий структурированную информацию о ваших товарах: названия, цены, описания, изображения и другие характеристики. SearchPro использует формат YML (Yandex Market Language) — стандарт Яндекс.Маркета, который поддерживается большинством CMS и интернет-магазинов.

🔄 Автообновление каждые 4 часа
📦 До 500 000 товаров
⚡ Мгновенная индексация

Минимальная структура фида

Ваш фид должен содержать корневой элемент <yml_catalog>, внутри которого находится <shop> с категориями и товарами:

XML (YML) 
<?xml version="1.0" encoding="UTF-8"?>
<yml_catalog date="2024-01-15 10:00">
  <shop>
    <name>Название вашего магазина</name>
    <company>ООО "Ваша компания"</company>
    <url>https://www.yoursite.ru</url>
    
    <currencies>
      <currency id="RUB" rate="1"/>
    </currencies>
    
    <categories>
      <category id="1">Электроника</category>
      <category id="2" parentId="1">Смартфоны</category>
      <category id="3" parentId="1">Ноутбуки</category>
      <category id="4">Одежда</category>
    </categories>
    
    <offers>
      <!-- Здесь будут ваши товары -->
    </offers>
  </shop>
</yml_catalog>

Пример описания товара

Каждый товар описывается в теге <offer>. Вот полный пример с комментариями:

XML 
<offer id="SKU-12345" available="true">
  <!-- Обязательные поля -->
  <name>Apple iPhone 15 Pro Max 256GB Titanium Blue</name>
  <url>https://yoursite.ru/product/iphone-15-pro-max</url>
  <price>149990</price>
  <currencyId>RUB</currencyId>
  <categoryId>2</categoryId>
  
  <!-- Рекомендуемые поля -->
  <picture>https://yoursite.ru/images/iphone-15-1.jpg</picture>
  <picture>https://yoursite.ru/images/iphone-15-2.jpg</picture>
  <vendor>Apple</vendor>
  <vendorCode>MU7A3</vendorCode>
  <description>
    Флагманский смартфон Apple с процессором A17 Pro, 
    титановым корпусом и продвинутой камерой 48 Мп.
    Поддержка USB-C и Action Button.
  </description>
  
  <!-- Дополнительные поля -->
  <oldprice>169990</oldprice>
  <model>iPhone 15 Pro Max</model>
  <typePrefix>Смартфон</typePrefix>
  
  <!-- Характеристики (param) -->
  <param name="Цвет">Titanium Blue</param>
  <param name="Память">256 ГБ</param>
  <param name="Диагональ экрана">6.7"</param>
  <param name="Операционная система">iOS 17</param>
</offer>

Справочник полей

Обязательные поля

Поле Описание Пример
id (атрибут) Уникальный идентификатор товара (артикул, SKU) SKU-12345
name Полное название товара. Включайте бренд, модель, важные характеристики Apple iPhone 15 Pro 256GB
url Прямая ссылка на страницу товара (абсолютный URL) https://site.ru/product/123
price Актуальная цена товара (число без пробелов и валюты) 149990
currencyId Код валюты (должен быть объявлен в currencies) RUB
categoryId ID категории из раздела categories 2

Рекомендуемые поля (улучшают качество поиска)

Поле Описание
picture URL изображения товара. Можно указать несколько тегов picture для галереи
description Текстовое описание товара. Важно для поиска! Чем подробнее — тем лучше
vendor Производитель / бренд товара
vendorCode Артикул производителя
available (атрибут) Наличие товара: true — в наличии, false — нет
oldprice Старая цена (для отображения скидки)
param Характеристики товара. Атрибут name — название, значение внутри тега

Проверка фида

После создания фида рекомендуем проверить его валидность:

  1. Откройте URL фида в браузере — он должен отображаться как XML
  2. Проверьте кодировку — кириллица должна отображаться корректно
  3. Используйте валидатор Яндекс.Вебмастера для проверки структуры
  4. Загрузите фид в SearchPro и проверьте количество распознанных товаров

Как создать фид для SearchPro

SearchPro поддерживает фиды в формате YML (Яндекс.Маркет) — это XML-файл с описанием ваших товаров. Большинство CMS (1С-Битрикс, OpenCart, WooCommerce и др.) умеют генерировать такие фиды автоматически.

Минимальная структура фида

XML (YML) 
<?xml version="1.0" encoding="UTF-8"?>
<yml_catalog date="2024-01-01">
  <shop>
    <name>Название магазина</name>
    <company>Компания</company>
    <url>https://example.com</url>
    
    <categories>
      <category id="1">Электроника</category>
      <category id="2" parentId="1">Смартфоны</category>
    </categories>
    
    <offers>
      <offer id="12345" available="true">
        <name>iPhone 15 Pro 256GB</name>
        <url>https://example.com/product/12345</url>
        <price>129990</price>
        <oldprice>149990</oldprice>
        <currencyId>RUB</currencyId>
        <categoryId>2</categoryId>
        <picture>https://example.com/images/12345.jpg</picture>
        <vendor>Apple</vendor>
        <description>Описание товара...</description>
      </offer>
    </offers>
  </shop>
</yml_catalog>

Обязательные поля товара

Поле Описание Пример
id Уникальный ID товара 12345
name Название товара iPhone 15 Pro
url Ссылка на страницу товара https://site.ru/product/123
price Цена товара 129990

Рекомендуемые поля

Поле Описание
picture URL изображения товара (можно несколько)
description Описание товара (улучшает качество поиска)
vendor Производитель/бренд
categoryId ID категории из раздела categories
oldprice Старая цена (для отображения скидки)
available Наличие: true/false

Советы

  • Размещайте фид на вашем сервере и укажите прямую ссылку
  • Обновляйте фид при изменении каталога (минимум раз в день)
  • Используйте кодировку UTF-8
  • Заполняйте description — это улучшает релевантность поиска
  • Максимальный размер фида: 50 МБ
